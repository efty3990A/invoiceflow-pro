# Marketplace product listing draft

## Product name
InvoiceFlow Pro — Responsive Invoice Maker

## Short description
A lightweight, responsive, browser-based invoice maker with live A4 preview, business logo, multiple line items, tax and discount calculations, invoice history, JSON backup/restore and print-to-PDF export.

## Features
- No installation, server, database or build tools required
- Responsive HTML/CSS/JavaScript source code
- Live invoice preview
- Business logo upload
- Three invoice preview themes
- Multiple line items and automatic totals
- Eight currency display options
- Tax and fixed discount fields
- Payment status label
- Local invoice history and draft storage
- JSON backup and restore
- A4 print stylesheet

## Requirements
A modern web browser. The application runs as a static client-side web app.

## Included files
Complete modular source code, setup guide, README, buyer license draft, changelog, AI coding guide, calculation tests, manual test plan, seller release checklist and this listing draft.

## Limitations
Data is stored locally in the browser; it is not synchronized across devices. PDF export uses the browser's print dialog. Currency selection does not convert exchange rates. Tax calculations are generic arithmetic and do not implement country-specific tax rules.
